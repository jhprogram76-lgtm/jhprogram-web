Términos y Condiciones

JH Program Studio

Estos términos regulan la relación entre JH Program Studio y quienes contratan sus servicios de desarrollo web, marketing digital y branding a través de este sitio o del formulario de contacto.

1. Objeto del servicio

JH Program Studio ofrece servicios de diseño y desarrollo de páginas web, aplicaciones a medida, marketing digital y branding, cuyo alcance concreto se define de forma individual para cada proyecto tras el contacto inicial a través del formulario del sitio.

2. Presupuestos y contratación

Los presupuestos facilitados a través del formulario de contacto son orientativos hasta que ambas partes confirmen por escrito (correo electrónico) el alcance final, precio y plazos del proyecto. Ningún trabajo comienza sin esa confirmación expresa.

3. Plazos de entrega

Los plazos se acuerdan de forma individual según la complejidad del proyecto. Los retrasos derivados de la falta de entrega de contenidos, accesos o feedback por parte del cliente no serán responsabilidad de JH Program Studio.

4. Propiedad y entrega del código

Una vez abonado el importe acordado en su totalidad, el cliente pasa a ser propietario del código y los archivos entregados para su proyecto, salvo librerías, plantillas o recursos de terceros sujetos a sus propias licencias.

5. Modificaciones posteriores

El mantenimiento, ampliaciones o modificaciones posteriores a la entrega del proyecto no están incluidos salvo que se acuerde expresamente, y se presupuestarán de forma independiente.

6. Limitación de responsabilidad

JH Program Studio no se hace responsable del uso que el cliente haga de la web entregada, ni de interrupciones del servicio derivadas del proveedor de hosting, dominio o de terceros ajenos a nuestro control.

7. Contacto

Para cualquier duda sobre estos términos, puedes escribirnos a info@jhprogramstudio.com.
